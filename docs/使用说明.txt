MathType 文本编辑器 v2

使用流程
1. 启动桌面的“MathType 一键公式”或“MathType 文本编辑器”快捷方式。
2. 从 Word、浏览器或聊天页面复制整段内容，在软件编辑区按 Ctrl+V。
   默认保留剪贴板中的富文本格式，并自动转换其中的公式。
3. 在软件中继续编辑文字、字体、字号、加粗、颜色和对齐方式。
   双击公式可用 MathType 编辑；完成后按 Ctrl+F4 关闭公式窗口返回软件。
4. 在目标 Word 文档中放好光标。回到软件，在底部选择正确的 Word 文档。
   新打开的文档可点击“刷新”后选择。
5. 点击“插入回 Word”，整段文字与公式一起插入。Word 中 Ctrl+Z 可撤销插入。

原文和插入位置
软件只在点击“插入回 Word”后写入选定的文档。
在 Word 有选区时，会插在选区末尾，不自动覆盖选区。
因此若从 Word 复制一段再转换，需自行决定保留或替换原段落。
后台转换使用独立的 Microsoft Word 实例，不在原计算书中做中间转换。

文字格式
支持保留富文本剪贴板里的字体、字号、加粗、斜体、下划线、颜色和常见段落格式。
公式转换只替换公式片段，不重新生成其他文字。
RTF 来源优先保留；浏览器 HTML 来源保留其提供的文字格式，并提取公式源码。
如果复制时得到的只是纯文本，原来的字号、颜色等已经不在剪贴板中，无法恢复；
此时按编辑区当前格式粘贴，默认宋体 12 磅。
本软件用于正文片段编辑；复杂页面布局、分节、页眉页脚、脚注和复杂表格请在 Word 中处理。

可识别的公式
行内：\( ... \)、$ ... $
独立公式：\[ ... \]、$$ ... $$、equation / equation* 环境。
支持 latex / tex / math 代码块，以及 [ 和 ] 分别占一行的常见复制格式。
也识别普通括号内包含明确 TeX 命令的表达式，例如 (E=2.06\times10^8)。
支持含源码的 KaTeX、MathJax、MathML 浏览器富文本；不会重复导入同一个公式的视觉层。
从 Word 或 RTF 粘贴的已有 MathType 对象保持可编辑，不再双向切换成代码。
tag 编号会提取并保留为公式后方的文字，不自动重排编号或生成交叉引用。
不完整或转换失败的公式保留代码，点击“查看提示”了解原因。
公式截图或纯图片不能直接识别为可编辑公式；MathType 也不支持全部 LaTeX 命令。
Word 原生公式不是本版 TeX 扫描的识别对象，本版不会承诺将其全部转成 MathType。

编辑和撤销
粘贴后自动转换可以取消勾选，之后点击“转换剩余公式”手动批量处理。
新输入的公式在“转换剩余公式”或插回 Word 时转换。
“撤销本次转换”恢复最近一批转换前的富文本。
如果转换后已经继续编辑，工具会保留新修改；请在编辑区用 Ctrl+Z 逐步撤销。
“停止转换”在当前一条公式处理完成后停止，其余公式保留代码。
点击“示例”可查看带字号、加粗、颜色、行内和独立公式的示例；已有内容时追加示例。

草稿
“保存草稿”保存 RTF，其中包含可编辑的 MathType 对象。
“打开草稿”可继续编辑，Word 也能打开该 RTF 文件。
程序还会在本机 LocalAppData\MathTypeOneClick\draft.rtf 保存最近内容，重启恢复。
关闭软件会保存草稿并结束软件自己启动的后台 Word，不关闭用户的目标 Word 文档。
草稿不上传到网络。

环境
需要 Microsoft Word、MathType 7，以及 Word 中可用的 MathType 加载项。
无需安装 Python、Node 或开发环境。
本版使用编辑器界面，不再注册上一版的全局 Ctrl+Alt 快捷键；Ctrl+V 在编辑区内使用。
上一版程序和说明保存在“旧版_v1”文件夹中。

维护
主程序：MathType一键公式.exe
源代码：MathTypeEditor.cs、FormulaText.cs、WordBridge.cs、EditorTests.cs
构建：运行 build.ps1，使用 Windows 自带 .NET Framework 编译器。
自检：MathType一键公式.exe --self-test
集成检查：MathType一键公式.exe --integration-test（自动启动独立 Word 进行验证）。
