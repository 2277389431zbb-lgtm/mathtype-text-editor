# 验证范围

本地验证日期：2026-10-28。

验证环境为 Windows、Microsoft Word 2024（Word 16）和 MathType 7.12.3。

自动化检查共 33 项通过，覆盖混合文字公式扫描、公式边界与编号、Word 软换行、KaTeX/MathML、MathType OLE 对象、字体字号、加粗颜色、段落缩进对齐，以及 RTF 保存后重新打开。

实际界面另行验证了：

- 在软件中自动转换行内与独立公式。
- 双击软件中的公式，使用 MathType 打开，再关闭返回软件。
- 将编辑结果插入独立的 Word 测试文档。
- Word 中保留蓝色加粗标题、红色加粗结论和 MathType 对象。
- 从 Word 复制混合内容后，在软件中按 Ctrl+V：原有 MathType 对象保留，新 TeX 自动转换，文字格式保留。
- 关闭程序、保存草稿，再次启动后恢复正文与公式对象。

复杂页面排版、图片公式和 Word 原生公式的限制见使用说明。验证报告中的机器路径和本地草稿未加入仓库。
